BrickSim is an open-source research simulator designed for developing and benchmarking robot manipulation policies on interlocking brick assembly tasks. Built on top of NVIDIA Isaac Sim and Isaac Lab, it provides high-fidelity physics for stud-hole connection detection, breakage modeling, and multi-brick structure management — all accessible from Python.

## What BrickSim Provides

BrickSim targets the robotics research community working on manipulation of structured, interlocking assemblies. It provides:

- **Automatic assembly detection** — the physics engine detects when a robot presses a brick's hole onto a stud within configurable force and alignment thresholds, and rigidly joins the parts automatically.
- **Breakage modeling** — a clutch-compliance model determines when sufficient separation force causes a connection to break, with independent tuning of axial, radial, and tangential compliance.
- **Isaac Lab RL environment** — a ready-to-train `AssembleBrickEnv` that exposes state-based, RGB, and RGB-D observation modes, shaped rewards, and an expert policy for data collection.
- **Topology serialization** — a `JsonTopology` schema for representing multi-brick assemblies with parts, stud-hole connections, and pose hints; importable and exportable at runtime.
- **Multi-format structure import** — load structures from BrickSim topology JSON, legolization JSON, or the StableText2Brick line format.
- **Static stability analysis** — the optional `stablelego` extra uses Gurobi to compute per-brick stability heatmaps via a Mixed Integer Program.

## Quick Install

```bash
uv pip install "bricksim[all]" \
  --index https://dl.cloudsmith.io/public/bricksim/bricksim/python/simple/ \
  --override <(printf 'pywin32==306 ; sys_platform == "win32"\n')
```

Then open an interactive stage:

```bash
uv run bricksim
```

See the [Quickstart](/quickstart) for the full walkthrough, or the [Installation](/installation) page for building from source.
